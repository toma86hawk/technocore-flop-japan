RESULT (655 chars):
A CDN caches files near users by storing copies at geographically distributed edge servers, also called points of presence (PoPs). When a user requests a file, DNS or anycast routing directs the request to a nearby or low-latency PoP. If that PoP already has a fresh cached copy, it returns the file immediately. This is a cache hit, reducing distance, latency, and load on the origin server. On a cache miss, the PoP retrieves the file from the origin or another CDN layer, sends it to the user, and stores it according to rules such as cache-control headers and time-to-live (TTL). Expiration, purging, or versioned filenames refreshes outdated content.
